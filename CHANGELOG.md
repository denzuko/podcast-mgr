## [1.0] — 2026-04-14

### Added

- `main.c` — FastCGI SPA worker for managing `feeds.xml`.
  Routes: GET /index, /list, /add, /edit; POST /save, /delete.
  Built on the BCHS stack: kcgi, khtml, kcgixml, mrvladus/xml.h, tsoding/sv.
- `sandbox.h` — Portable privilege-drop.
  Linux: seccomp(2) BPF allowlist (rw profile).
  FreeBSD: Capsicum cap_enter(2) + cap_rights_limit(2).
  OpenBSD: pledge(2) "stdio unix inet wpath cpath".
  NetBSD: pledge(2) same promises, distinct signature.
- `nob.c` — Build driver (tsoding/nob).
- `podcast.sh` — tcsh cron script.
  Reads `feeds.xml`, validates against `feeds.xsd`, downloads episodes
  via curl, optionally generates an M3U playlist.
- `feeds.xsd` — XML Schema constraining `feeds.xml` structure and
  enumerated attribute values (scope, day, pull_time).
- `index.cgi.8` — mdoc(7) system manager manpage.
- `sbom.json` — CycloneDX 1.6 Software Bill of Materials
  (generated by cdxgen 12.1.5).
- `podcast_mgr.sarif` — SARIF 2.1.0 security scan report.
  cppcheck 2.13.0: zero findings post-fix.
  OSV CVE scan: zero findings across all versioned components.
- `CODEOWNERS` — All paths assigned to @denzuko.
- `.githooks/post-checkout` — Compiles nob and builds index.cgi
  automatically on initial clone.
- Branch protection on `main`: enforce_admins, required_linear_history,
  no force-push, no deletion, CODEOWNERS review required.

### Fixed

- `podcast.sh`: `set temp_files = ()` — was `= ""`, causing phantom
  empty-string element on first loop iteration in cleanup.
- `main.c`: `const struct kpair *kp` in `validate_fields` and
  `PAGE_SAVE` — was non-const, flagged by cppcheck CWE-398.
- `main.c`: Replaced ooxi/xml.c API calls (`xml_parse_document`,
  `xml_document_root`, `xml_node_attribute_content`) with correct
  mrvladus/xml.h API (`xml_parse_string`, `xml_node_child_at`,
  `xml_node_attr`).
- `main.c`: `#define XML_H_IMPLEMENTATION` — was `XML_IMPLEMENTATION`,
  preventing function bodies from compiling in.
- `main.c`: `xml_node_serialize()` not used — it emits `</tag attr="v">`
  for self-closing nodes.  Serialisation now uses `XMLString` directly.
- `main.c`: Arena-copy `kp->val` in `PAGE_SAVE` before `khttp_free()`
  invalidates kcgi's request struct — was a use-after-free.
- `main.c`: Two-label `fatal:`/`fatal_pre:` exit pattern replaced with
  single `done:` label, `fcgi = NULL` initialisation, and NULL-guard.
- `main.c`: Removed `send_html`/`send_partial` duplication — collapsed
  to single `send_response`.

### Security

- cppcheck static analysis: 0 findings (post-fix).
- OSV CVE scan: 0 findings across libc6-dev 2.39, libgcc-13-dev 13.3,
  libstdc++-13-dev 13.3, linux-libc-dev 6.8, libfreetype-dev 2.13,
  libpython3.12-dev 3.12.
- NVD keyword search: 0 CVEs for kcgi, xml.h.

### Removed

- `PAGE_SYNC` route and `trigger_sync()` — podcast.sh is a cron job,
  not invoked by the CGI.
- CSRF token machinery — single-user local-network tool; cross-origin
  threat model does not apply.
- Sync rate-limiting counter — no concurrent sync surface to protect.
- `path_is_safe()` traversal check on `XDG_CONFIG_HOME` — operator
  controls their own environment.
- `send_html`/`send_partial` distinction — identical after CSRF removal.

## [Unreleased]

- `main.c`: `Arena arena = {0}` — replaced `arena_init(4M)` with
  zero-value init matching the real tsoding/arena API.

### Added

- `vex.cdx.json` — CycloneDX 1.6 VEX document. 12 not_affected statements
  for CVEs matched against build-host dependencies (libc6-dev, libglib2.0-dev,
  libpython3.12-dev, linux-libc-dev) by NVD CPE. Four justification categories:
  (1) glibc APIs not called (iconv, glob, nscd, crypt) — confirmed by cflow.txt;
  (2) libglib2.0-dev not linked at runtime — link flags are -lkcgixml -lkhtml -lkcgi -lz only;
  (3) libpython3.12-dev is a build-host header dep — no Python runtime shipped;
  (4) linux-libc-dev NVD CPE false positive (wu-ftpd CVE matched against kernel headers).
  Document linked to SBOM via sbom-serial property.

### Changed

- `nob.c` refactored as a full subcommand runner. All administrative tasks
  are now `./nob <subcommand>` — no separate scripts needed at the CLI:

  | Subcommand   | What it runs |
  |--------------|--------------|
  | `(none)`, `build` | compile `index.cgi` |
  | `test`       | `test_main` + `test_nob.sh` |
  | `test-unit`  | `test_main` (52 xUnit cases) |
  | `test-e2e`   | `test_nob.sh` (22 build tests) |
  | `ast`        | clang AST dump → `scripts/gen_ast.sh --filter` → `ast.json` |
  | `sbom`       | cdxgen → `sbom.json` |
  | `sarif`      | cppcheck + `scripts/gen_sarif.py` → `podcast_mgr.sarif` |
  | `vex`        | OPA `policy/vex.rego` validate `vex.cdx.json` |
  | `policy`     | full OPA gate: sarif + sbom + vex + ast |
  | `clean`      | remove `index.cgi`, `test_main`, `nob` |
  | `all`        | build + test + ast + sbom + sarif + policy |
  | `help`       | print usage |

- `scripts/gen_ast.sh` updated with `--filter` and `--check` modes.
  `--filter` skips the clang dump step (used by `./nob ast`).
  `--check` exits 1 if `ast.json` is stale (useful in CI).

- `test_nob.sh` TARGET grep updated to tolerate whitespace after `#define`.
